# FAIRFRAME SPRINT 2 IMPLEMENTATION PROMPT

Read the attached FAIRFRAME_FOUNDER_BIBLE_V1.md and use it as the source of truth for FairFrame going forward.

Before making any changes, understand the following:

FairFrame is not a photography app.

FairFrame is a Visual Storytelling Coach.

Mission:
Teach People How To See.

The MVP proved:
- The workflow works.
- The scorecard works.
- The concept works.

The next phase is not about adding more features.

The next phase is about making Chief feel real.

## Sprint 2 Goals

Priority 1:
Remove all camera mode toggles.

Remove:
- Visual Mode
- Story Mode
- Subject Mode
- Scout Mode

Users should not have to make these decisions.

---

Priority 2:
Automatically determine:

- Subject Present Mode
- Location Scout Mode

Chief should decide this automatically.

---

Priority 3:
Move Story Context.

Story Context should become an optional enhancement after the first analysis.

New flow:

Open App
→ Take Photo
→ Chief Analysis
→ Chief Report
→ Optional Story Context
→ Enhanced Report

---

Priority 4:
Redesign Chief's evaluation process.

Chief should evaluate:

1. Communication
2. Focus
3. Clarity
4. Context
5. Storytelling
6. Craft

---

Priority 5:
Chief must reference actual visible elements in the image.

Bad:

"Layer foreground and background."

Good:

"The shelving on the left side of the frame creates visual weight, but there is no clear subject for the eye to land on."

Users should feel:

"Chief actually looked at my image."

---

Priority 6:
Redesign scoring.

Display:

- Communication
- Focus
- Clarity
- Context
- Storytelling
- Craft

Combine into:

Visual Storytelling Score

---

Priority 7:
Redesign Results Screen.

Make the analyzed image significantly larger.

The image is the product.

The report supports the image.

Add:

## What Chief Sees

Examples:

- Focus: Strong
- Clarity: Moderate
- Context: Strong
- Storytelling: Weak
- Craft: Good

---

Priority 8:
Maintain design direction.

Continue drawing inspiration from:

- Apple Pro Apps
- Blackmagic Design
- Lightroom
- Sony Alpha ecosystem
- Broadcast production tools

Avoid:

- Chatbot UI
- Social media design
- Gaming aesthetics
- AI sparkle branding

---

Final Goal:

Make Chief feel like a veteran award-winning visual storytelling coach who is evaluating the user's specific image.

Before implementing, explain your technical plan and proposed changes.
