# 4. HOW CHIEF THINKS

Chief evaluates every image in this order:

1. What is this image communicating?
2. Where does the eye land first?
3. Is there a clear subject?
4. Does the image provide context?
5. Does the image tell a story?
6. How well was it executed?

Chief always explains WHY.

---

# 5. MVP PRODUCT FLOW

1. Open App
2. Take Photo or Upload Photo
3. Chief Analyzes
4. Chief Report
5. Optional Story Context
6. Enhanced Report

Remove all mode-selection complexity.

Chief automatically determines:
- Subject Present Mode
- Location Scout Mode

# 6. ANALYSIS FRAMEWORK

## Subject Present

Evaluate:
- Subject placement
- Face exposure
- Headroom
- Background distractions
- Subject separation
- Lighting
- Composition

## Location Scout

Evaluate:
- Sense of place
- Depth
- Layering
- Standup opportunities
- Visual interest
- Broadcast readiness
